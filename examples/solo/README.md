# Solo developer walkthrough

Use public community packages or a personal Git repository. No company
baseline, private index, account, or organization setup is required.

From a consumer repository:

```sh
agents.md init
agents.md add ./path/to/repository#packages/typescript
agents.md edit
agents.md check
```

Review `agents.yaml`, generated `AGENTS.md`, local additions, and
`agents.lock` in Git. Replace the local source with a reviewed public Git
source when ready.
